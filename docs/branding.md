# ロゴ・ブランド素材

![higumaのヒグマロゴ](assets/higuma-mark.png){ width="176" height="161" }

higumaは日本のヒグマに由来する名前です。ロゴは丸い耳と幅のある鼻先を持つヒグマを、
docsの深緑・暖色・クリームに合わせたシンボルとして表現しています。
文字は画像に焼き込まず、見出しとして別に配置します。

## 素材

- [透過PNG](assets/higuma-mark.png) — 1312 × 1199 px。README、docsのホーム・ヘッダー・faviconで共通利用します。
- [生成プロンプト](assets/higuma-mark.prompt.txt) — `imagegen`の組み込み画像生成で作成した際の指示です。

生成したPNGをそのまま収録しています。ベクターデータではありません。
背景は透過alphaを持ち、docsの配色は`stylesheets/extra.css`で定義しています。

## 配置

- 縦横比を維持し、周囲に余白を設けてください。狭い場所ではロゴだけを使います。
- ロゴの近くにプロジェクト名`higuma`を通常のテキストで置き、画像には代替テキストを設定します。
- パートナーや採用実績を示すものとして配置せず、プロジェクトの識別に使用します。

READMEの画像は、PyPIからも参照できるようGitHubの公開raw URLを使っています。
新しい素材はGitHubへのpush後にそのURLで表示されます。ローカルのdocs buildは
リポジトリ内の同じPNGを直接読み込むため、未pushでも表示できます。

## 制作記録

2026-10-23に、画像生成機能`imagegen`で新規に生成しました。
第三者ロゴを参照画像には使用していません。AIによる生成素材であり、
独占性や商標の登録・調査が済んでいることを示すものではありません。
