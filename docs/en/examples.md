# Examples

The 0.6.0 examples include `csr_app.py` (dependency-free browser CSR,
History API, fetch; open `/app/`) and `vite_ssr.py` (Python HTML with Vite CSS and
module preloads). Run `higuma run examples.csr_app:create_app` for the former.
For the latter, generate your own `.vite/manifest.json` with `build.manifest: true`,
set Vite's base to `/build/`, and point `HIGUMA_FRONTEND_DIST` to that build.
See [frontend integration](frontend.md) for development/production instructions.

See [Flask compatibility](flask-compat.md) for `examples/flask_mount.py`
(install `higuma[compat]`) and `examples/flask_compat.py` (g, sessions, flash,
URL generation, and CSRF; requires `HIGUMA_SECRET_KEY`).

`security_tokens_roles.py` additionally requires `HIGUMA_DEMO_PASSWORD_HASH`,
generated by `PasswordHasher().hash(...)`. First GET `/csrf-token`, retain its
cookie and token, then POST with `X-CSRF-Token` and JSON containing
`user_id="usr_example123"` and your `password`. User IDs alone cannot log in.

## Basic execution

See [Server interfaces](server-interfaces.md). Try
`uvicorn examples.server_modes:asgi_app --lifespan on --ws websockets-sansio`,
`python -m examples.server_modes --mode wsgi`, or `python -m examples.server_modes`
for the same HTTP endpoints. The reference WSGI server is development-only.

Install from the repository root, then run an example:

```bash
python -m pip install -e .
python examples/routing_async.py
python examples/modern_typed_api.py
python examples/streaming_sse.py
python examples/testing_client.py
```

Factory-style examples also work through the CLI:

```bash
higuma run examples.orm_blog:create_app --port 8000
higuma run examples.blueprint_hooks:create_app --port 8000
higuma run examples.supervised_app:app --processes 4
```

## Examples that use secrets

Set a random development value of at least 32 bytes. Do not save a real secret
in shell history or the repository.

=== "PowerShell"

    ```powershell
    $env:HIGUMA_SECRET_KEY = python -c "import secrets; print(secrets.token_urlsafe(32))"
    python examples/authentication.py
    ```

=== "POSIX shell"

    ```bash
    export HIGUMA_SECRET_KEY="$(python -c 'import secrets; print(secrets.token_urlsafe(32))')"
    python examples/authentication.py
    ```

For the CSRF-protected login, first call `GET /csrf` to create a token in the
same client session. Send that value to `POST /login` in the `X-CSRF-Token`
header or `_csrf_token` form field.

The OAuth example additionally requires `GOOGLE_CLIENT_ID` and
`GOOGLE_CLIENT_SECRET`. Register its exact redirect URI with the provider. The
example makes real requests to Google.

## Try request lifecycle hooks {#request-lifecycle}

Set a development secret as above, then start from the repository root:

```bash
higuma run examples.flask_lifecycle:create_app --port 8000
```

GET `/counter/` with a cookie-preserving client. The response contains `count`,
`csrf_token`, and a `Server-Timing` header. Send that token as `X-CSRF-Token`
when POSTing JSON `{"increment": 2}` to `/counter/increment`. Check
`X-Counter-Saved: yes`, then GET again to confirm persistence. Missing CSRF
tokens return 403; invalid increments return 400.

The same flow without starting a server:

```python
from examples.flask_lifecycle import create_app

with create_app().test_client() as client:
    token = client.get("/counter/").get_json()["csrf_token"]
    response = client.post(
        "/counter/increment", json={"increment": 2}, headers={"X-CSRF-Token": token}
    )
    assert response.get_json()["count"] == 2
    assert response.headers["X-Counter-Saved"] == "yes"
    assert client.get("/counter/").get_json()["count"] == 2
```

This is demo state in a signed cookie, not a durable or concurrency-safe database
counter. Production needs HTTPS, `secure=True`, appropriate host/proxy settings,
and external state management. See [Flask compatibility](flask-compat.md) and
[Testing](testing.md) for ordering, early responses, and context boundaries.

## Examples that create files

`multipart_upload.py` stores files in `examples/uploads/` by default. Set
`HIGUMA_UPLOAD_DIR` to use a dedicated directory. The example normalizes names
and checks a 2 MiB limit and an extension allowlist; production systems should
also add content inspection, malware scanning, authorization, quotas, and
object storage.

`orm_blog.py` creates `examples/blog.sqlite3`. Run `orm_fields.py` for an ORM
exercise that uses only in-memory SQLite.

See [Deployment](deployment.md) for the production Supervisor topology. A
directly exposed Supervisor cannot support client-IP rate limits or audit logs.
