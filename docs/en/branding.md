# Brand assets

![The higuma brown bear mark](../assets/higuma-mark.png){ width="176" height="161" }

Higuma is named after the Japanese brown bear. Its mark combines rounded ears
and a broad muzzle with the documentation's forest green, rust, and cream palette.
The project name is typeset separately rather than embedded in the image.

## Downloads

- [Transparent PNG](../assets/higuma-mark.png) — 1312 × 1199 px, shared by the README, documentation home, header, and favicon.
- [Generation prompt](../assets/higuma-mark.prompt.txt) — the brief used with the built-in `imagegen` tool.

The generated PNG is included without image edits. It has a transparent alpha
channel and is not a vector asset. Documentation colors live in `stylesheets/extra.css`.

## Placement

- Preserve the aspect ratio and leave clear space. Use just the mark in narrow layouts.
- Set the name `higuma` as real text nearby and provide meaningful image alt text.
- Use the mark to identify this project, not to imply adoption, partnership, or endorsement.

The README uses a public GitHub raw image URL so the logo also works on PyPI.
New assets become available at that URL after pushing to GitHub. Local docs
builds load the same PNG directly from the repository and work before pushing.

## Provenance

Generated from a new prompt on 2026-10-23 using the built-in `imagegen` tool.
No third-party logo was supplied as a reference image. This is an AI-generated
asset; its inclusion does not assert exclusivity or completed trademark clearance.
